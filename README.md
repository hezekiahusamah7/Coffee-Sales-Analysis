# Coffee Sales Analysis Project

## Overview
This project analyzes coffee sales data entirely in Excel. It demonstrates how raw data was cleaned and transformed into a structured dataset, then visualized through PivotTables and dashboards.

## Data
- **Raw Data:** `coffeeOrdersData (1).xlsx`
- **Cleaned Data & Dashboard:** `My Project on coffeeOrdersData.xlsx`

## Process
- Imported and reviewed the raw Excel dataset
- Cleaned and organized the data for consistency
- Built PivotTables to explore customer loyalty, product performance, and regional sales
- Designed a dashboard to present insights clearly

## Tools Used
- Microsoft Excel 2013
- GitHub (for version control and sharing)

## Results
- Identified loyalty card holders
- Visualized sales by country and roast type
- Created a professional dashboard for insights

Future work will expand into Python for automation and advanced analytics.
